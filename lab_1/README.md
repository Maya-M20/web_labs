# The Gaming Shelf

The Gaming Shelf is an online board game shop developed as a frontend project.

The website allows users to browse board games, view product information, add games to the shopping cart, change the quantity of products, remove products from the cart, and place an order.

## Live Demo

The deployed website is available here:

https://maya-m20.github.io/web_labs/lab_1/

## Technologies

The project was created using:

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Media Queries
- Browser Local Storage API

No CSS frameworks or JavaScript frameworks were used.
